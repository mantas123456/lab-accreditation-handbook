# Glossary

Short definitions in our own words. This list grows with each chapter.

CAPA
:   Corrective and preventive action. Finding the cause of a problem and
    fixing it so it does not happen again.

Control sample
:   A stable, homogeneous material tested alongside routine samples to
    check that a run is in control. Also called a check sample or QC
    sample.

Coverage factor (k)
:   The number you multiply the combined standard uncertainty by to get
    the expanded uncertainty. About 2 for 95 % coverage.

CRM
:   Certified reference material. A material with a property value and its
    uncertainty stated on a certificate, traceable to a reference. Used to
    check bias.

Decision rule
:   An agreed way of taking measurement uncertainty into account when
    stating whether a result meets a limit.

Expanded uncertainty (U)
:   An interval around the result expected to contain the true value with
    a stated probability, usually about 95 %.

LOD, LOQ
:   Limit of detection and limit of quantification. The smallest amount a
    method can detect, and the smallest it can measure with acceptable
    precision.

Measurand
:   The exact quantity you intend to measure, including the conditions
    that define it.

PT
:   Proficiency testing. Several labs test the same material and each
    lab's result is scored against an assigned value.

Traceability
:   An unbroken, documented chain of calibrations linking a result to a
    reference, usually the SI units, with an uncertainty at each step.

Westgard rules
:   A set of control-chart rules that tell random errors from systematic
    shifts and drifts.

z-score
:   A PT score: (your result − assigned value) ÷ the standard deviation
    for proficiency assessment. |z| ≤ 2 is satisfactory, 2 < |z| < 3
    questionable, |z| ≥ 3 unsatisfactory.
