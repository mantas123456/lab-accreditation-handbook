# Roadmap

The handbook grows in versions. Each one is complete on its own, so the site
is useful at every step.

| Version | Adds | Status |
|---|---|---|
| **0.1 Skeleton site** | The site, the clause map, the chapter format, and two full chapters: [7.6 Measurement uncertainty](process/7-6-measurement-uncertainty.md) and [7.7 Ensuring the validity of results](process/7-7-validity-of-results.md) | Done |
| **0.2 Process chapters** | All of clause 7: contract review, methods, sampling, item handling, records, reporting, complaints, nonconforming work, data management | Done |
| **0.3 All clauses** | Clauses 4, 5, 6 and 8; the Start here chapters, including accreditation in Malta; a CI check that every clause has a chapter | Done (draft, not yet reviewed) |
| **0.4 Template pack** | 24 editable Word and Excel [templates](template-library/index.md), linked from each clause, built and tested automatically | Done |
| **0.5 Interactive tools** | A [gap analysis](tools/gap-analysis.md) with readiness scores and a to-do list, and an [internal audit planner](tools/audit-planner.md), both running entirely in your browser | **Live** |
| 1.0 Reviewed release | Review by practising quality managers or assessors, a PDF edition and a citable DOI | Next |
