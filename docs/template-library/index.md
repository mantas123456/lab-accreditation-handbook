# Templates library

<!-- template-pack -->

The zip holds every template below, plus a README with the licence and the
clauses each file supports.

Editable templates for a small testing or calibration lab, free under
[CC BY 4.0](../about.md#licence): use and adapt them, including commercially,
with credit. Each one is linked from the chapter for its clause.

- **Word** files are forms, checklists, procedures and records. Replace the
  text in italics and the blank fields with your own.
- **Excel** files are registers, plans and budgets. Each has an **About**
  sheet with instructions; rows in grey italics are examples from a made-up
  lab, to replace or delete. Dropdown lists, formulas and highlighting
  (overdue dates, high risk scores, questionable PT results) are built in.

!!! warning "Adapt before use"
    A template is a starting point. Make it match how your lab actually
    works, and check it against your accreditation body's rules. An assessor
    will notice a form copied without thought.

<!-- template-library -->

The templates are built from plain-text sources in the
[repository](https://github.com/mantas123456/lab-accreditation-handbook/tree/main/templates),
so you can suggest an improvement through GitHub.
