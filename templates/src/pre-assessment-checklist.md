# Before you apply

| Check | Status | Owner / date |
|---|---|---|
| Scope written precisely: material, property, method, range | ☐ R ☐ P ☐ N | |
| The system has run for some months, with records to show it | ☐ R ☐ P ☐ N | |
| At least one full internal audit cycle completed | ☐ R ☐ P ☐ N | |
| A management review held, with all inputs | ☐ R ☐ P ☐ N | |
| The accreditation body's own rules read (application, PT, traceability, use of the mark) | ☐ R ☐ P ☐ N | |
